## 冻结验收标准

### 任务模型页（第 4 项）

1. 七个任务页改为声明式 `items` 子页面，每行是原生 `Setting`；`TaskDetails.svelte`、`TaskModelCard.svelte` 移除，任务页不再走 `SvelteSettingPage`。
2. 设置搜索能找到任务页内的设置：真实宿主中搜索「温度」「最大输出」「推理强度」返回本插件任务页结果。
3. 行为不变：服务与模型的「沿用 / 指定」、参数三态（沿用 / 指定 / 不发送）、空值与越界校验不写入设置、参数来源与生效值说明、协议不支持与采样被抑制提示、能力覆盖、恢复默认、任务探针及配置变化后作废旧结果。原有行为测试改写后仍断言同一行为。
4. 未保存草稿（选了「指定」但值为空或无效）在同一次设置会话内离开再返回仍在；关闭设置页后丢弃。
5. 参数与能力放在任务页内的下一级子页面，首屏只有服务、模型、探针与恢复默认。

### 服务编辑框（第 5 项）

6. 添加与编辑服务改用宿主 `Modal` 与原生 `Setting` 行；`ProviderModal.svelte` 移除；表单状态、校验与配置组装抽成纯函数模块并有单元测试。
7. 行为不变：全部字段、按协议显示的能力与参数、校验规则与提示、连接测试（配置变化后作废旧结果）、保存失败提示、保存中禁止关闭、编辑时服务名不可改。API Key 默认隐藏，可切换显示。

### 无障碍走查（第 7 项）

8. 真实宿主中只用键盘完成：打开设置 → 添加服务 → 填写并测试 → 保存 → 进入任务页修改一个参数 → 返回；工作台识别概念输入与笔记操作可用 Tab 到达并以 Enter / Space 触发。焦点始终可见。
9. 通过 Chromium 无障碍树核对：插件的图标按钮与表单控件都有可读名称；不存在无名称的可聚焦元素。
10. 暗色与 Moonstone 亮色主题下，插件自定义的说明、警告、错误文字与背景对比度不低于 4.5:1（WCAG 2.2 AA）。发现的问题在本任务内修复。

### 质量门禁

11. `npm run check`、`npm run check:test`、`npm run lint`、`npm test`、`node --test scripts/*.node-test.mjs`、`npm run build` 全部通过，不放宽规则，不新增依赖。
12. 真实 Obsidian 中截取任务页与服务编辑框改动前后对比（暗色与亮色）；`dev:errors` 无新增错误；测试服务只在内存中，不读写 `data.json`。
13. `docs/DESIGN.md` 与 `docs/OBSIDIAN_UI_TESTING.md` 中涉及任务页与服务编辑框的描述同步更新。
