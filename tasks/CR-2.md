- **决策（mengde，2026-11-21）**：设置页迁移原生 API，工作台定向演进；不做首次使用引导；界面统一用「服务」指代聊天与嵌入接口配置；直接在 `feat/uiux-redesign` 实施，以改动前后截图对比验收。

## 冻结验收标准

### 设置页

1. `CRSettingTab` 用 `getSettingDefinitions()` 声明设置，Svelte 设置根组件和自绘标签页移除；`manifest.json` 与 `versions.json` 的最低版本改为 1.13.0。
2. Obsidian 设置搜索能找到插件的每个普通设置项：真实宿主中 `searchIndex` 的 `cognitive-razor` 条目数大于 0，搜索「发现相似笔记」「默认服务」「卡片」「并发」均返回本插件结果。
3. 信息顺序为：服务 → 默认服务与任务模型 → 笔记与卡片 → 生成与检索 → 显示 → 维护与备份。任务模型、保存位置、维护与备份使用原生子页面。
4. 未配置状态下首屏警告最多一处；不出现 `—·—` 之类的占位符；任务覆盖在一个入口内汇总，只有有问题的任务带警告状态。
5. 用户可见文字用「服务」，不再用「Provider」「连接」指代同一对象（协议名、API Key、Base URL 等专有名词除外）。
6. 行为不变：设置键、取值换算（秒与毫秒）、校验、保存失败提示与重试、连接测试与任务探针、位置预览后保存、导入导出、备份并重置、索引维护全部保留。原有行为测试改写后仍断言同一行为，不删除行为覆盖。

### 工作台

7. 去掉「工作台」大标题；设置入口改为带 `aria-label` 和提示的图标按钮。
8. 「当前笔记」区显示笔记名、类型与状态，拓展、核查、卡片和核查问题归入该区；当前文件不是知识节点时只显示一行说明，不显示三枚禁用按钮。
9. 笔记操作与识别概念的可用性规则一致：对应任务没有可用模型时禁用并说明原因。
10. 区块标题字号、字重和右侧动作样式统一；每个视图只有一个主按钮；焦点环与禁用态统一。

### 质量门禁

11. `npm run check`、`npm run check:test`、`npm run lint`、`npm test`、`node --test scripts/*.node-test.mjs`、`npm run build` 全部通过，不放宽规则，不新增依赖。
12. 真实 Obsidian 中截取改动前后对比：侧栏 240 / 300 / 427 px，暗色与亮色（Moonstone）主题；键盘走查设置与工作台；`dev:errors` 无新增错误；测试笔记清理完毕。
13. `docs/DESIGN.md` 与 `docs/REQUIREMENTS.md` 中涉及设置页结构的描述同步更新。
