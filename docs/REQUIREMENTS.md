# 产品需求

## 知识与判断

插件帮助使用者将材料组织为可见、可修改的知识结构。五种知识类型是领域、议题、理论、实体、机制；按实际指称选择模板，允许同一名称分别属于不同类型。AI 提供组织、写作与核查辅助，使用者保留最终判断。

节点名称采用同指、同范围的通行中英文名称，同一对象跨字段、跨分类组保持一致，正式复合名称保持完整。别名覆盖标准中文名、英文名及不同字形的繁体中文名，合并重复项。正文应解释概念、依据、条件与联系，自拟标题简明并遵循公共长度与格式规则，固定标题按对应阶段输出。

层级分类只列直属下一层，以覆盖父项范围为目标，证据不足时说明已知范围。每套分类保持统一依据、关系与相当粒度；划分依据或归属规则不同的标准分别分组，同依据同归属的异名体系合并，跨组交叉保留并说明。应用目标形成的通行领域可以列入；活动、研发阶段与流程本身不作为子领域。实体分类和核查使用一致的分类边界。

- 区分事实、解释、价值判断与行动建议，说明各自的证据、推理、立场或情境依据。
- 结论保留可追溯的来源或论证及失效条件；没有依据或尚未验证的内容明确标注，不以流畅表达代替可信度。
- 知识关联说明方向和含义（如属于、依赖、反驳），按解释需要选择，避免穷举无意义的关联。

## 创建与拓展

输入概念后，Define 返回五类候选；确认类型之前不创建持久节点。确认后按 Tag、该类型的 Write 阶段执行。自动核查开关在确认时固定，开启后在写作完成后进入 Verify。

创建不得覆盖已有同路径笔记。同名不同类型的节点可以分别存在。领域、议题、理论从正文结构拓展下位节点；实体、机制通过相似节点和抽象建议拓展。拓展结果经确认后进入创建流程。自动事实核查默认关闭。

## 核查

核查使用启动时的节点快照，区分正文事实、任务上下文与外部证据。报告只列有依据且可定位的问题，公式使用单美元行内定界符或双美元独立定界符；独立公式的起止符各占一行，公式内部括号保留数学含义。

核查成功后替换插件标记的核查报告并将状态设为 evergreen；提交时保留当前正文及标记块外内容。该状态表示流程完成，不代表科学正确性认证。

## 记忆卡片

默认知识目录为 `C-知识库/1-领域` 至 `C-知识库/5-机制`；卡片目录默认为 `D-习题库`，目录均可配置。卡片路径镜像知识库相对路径并追加 `-decks` 文件名后缀。

卡片只从合法知识节点生成，使用去掉 frontmatter 和插件核查标记块后的完整正文。卡片用于理解检查；模型构造的情境须标明其假设性质。支持 Decks 标题卡、双列表格与挖空，不设置固定数量目标。

入队时固定源路径、正文、目标路径和模型配置。卡片是独立任务，服务或模型留空时继承全局默认配置；不继承其他任务的专用覆盖。正常返回整批结果后一次性追加到镜像 `-decks.md`，保留既有内容与手工修改，不去重，不添加批次标题，不自动打开文件。

卡片生成不以核查完成为前提。取消或中断时不追加未完成结果；重载后运行中的卡片任务标为 interrupted，不自动重发。从源笔记重新生成才创建新的请求。

## 索引与合并

语义索引与重复检测可分别配置，默认开启，相似度阈值默认为 0.85。索引排除 frontmatter 和插件核查报告；索引文本受长度限制，卡片正文不沿用该限制。

重复候选由同类型向量相似度产生。相似度只提供候选，不等同于同一概念；用户可保留具有重要差异的节点。合并需选择主笔记、检查合并预览并确认，之后写入主笔记并将冗余笔记移入回收站。设置提供索引重建、补嵌入与清理等维护操作。

合并正文应成为一篇完整知识条目，保留两篇的独有事实、条件、数值、公式、来源与不确定性，收拢同义重复，不混同不同对象或分类依据。沿用对应类型已有材料的固定二级标题与顺序，不随意改名、合并标题或虚构缺失章节。无法裁决的矛盾既在正文对应章节呈现，也在预览冲突列表提示。插件核查报告不作为合并知识材料；别名、标签、父项和来源标识要求保留输入并集，最终以用户确认的编辑为准。

草稿生成后，主笔记或冗余笔记内容发生变化时，确认旧草稿须停止且不修改笔记，提示重新生成并检查草稿。确认后的主笔记写入与引用笔记链接修复，也不得覆盖各自快照之后的编辑；发现冲突时停止后续步骤并保留草稿与恢复记录。

合并按文件和阶段提交，不提供跨文件回滚。冲突前已经完成的写入保留；继续恢复仍须检查待写文件，不能强制覆盖修改。已经落盘且与目标全文一致的结果可以确认完成，避免检查点失败导致重复应用。冗余笔记在移入回收站前仍须与确认快照一致。

## 服务与执行

聊天支持 OpenAI Chat Completions、OpenAI Responses 和 Gemini Generate Content，嵌入使用 OpenAI Embeddings。任务留空的服务与模型继承默认配置；嵌入任务继承嵌入模型。搜索、思考参数、缓存与续接按协议及配置启用，只声明服务实际支持的能力。

服务协议由用户显式配置，不依模型名称猜测协议。任务参数只有继承、具体覆盖、明确省略三种状态，分别用缺省值、具体值和 null 表示。保留显式选择的服务；服务不可用时给出错误，不静默改用其他服务。

队列支持暂停、取消、筛选与手动重试。请求结果未知时进入 interrupted，不自动重发；重新请求需确认。运行记录和已落盘阶段结果用于恢复，但不会把跨进程账本当成计费证明。

## 备份保护范围

设置页的“备份并重置运行数据”备份插件设置及插件目录 data/，排除其中的 backups/，随后重置设置与运行态。

包含队列、工作流、向量、重复对及其他运行文件。不包含知识库 Markdown、卡片、附件、插件程序或提示词。保留正文不等于备份正文；笔记与卡片须使用独立库备份。

普通设置导出去掉 API Key。重置快照中的 settings.json 可能包含密钥，只能作为本地私密文件保存，不分享或上传。

快照布局与恢复操作见[运行数据备份与恢复](RUNTIME_BACKUP_RECOVERY.md)。
